①第一次打开：认领你的姓名

小程序第一次进入会先让你在全员名单里选中自己，点「确认是我的姓名」。这一步只做一次，之后不再出现。

它的作用是把你和小程序里的姓名绑在一起 —— 之后「我的任务」「能不能改这条」全部按这个身份判定。

③领需求：需求池与认领

最左边的页签「领需求」，是事情成形之前的落点。很多事最初只是一个念头 ——「得找财富部聊聊那个权益的事」。眼下这种念头无处可放：要么硬建成一条残缺的任务，要么留在微信聊天里。需求池承接这一段：需求是还没成形的事，任务是已经有人认领的事。

四个分段，各自装什么

  • 待认领 —— 等着人接的需求。点开一条就是去新建任务（= 把它领走）。
  • 我领的 —— 我已经领走、正在办的需求。
  • 我提的 —— 我记进去的需求（不管后来谁领走了）。
  • 已关闭 —— 决定不做了的需求，卡片上会显示关闭原因。

左右滑动列表即可切换分段。同一个需求可能同时出现在「我领的」和「我提的」里（我提的我自己领），这是正常的，两个分段问的是两件事。

一条需求长什么样

  • 标题（必填，一句话）+ 描述（选填）。
  • 对接部门 / 对接人 —— 纯外部联系人（"我们要去找谁聊"），不进人员体系、不参与任何权限，也不会出现在认领页或人员看板里。
  • 期望时间（选填，YYYY-MM-DD）。
  • 提出人（自动记）、状态、领走人、关闭原因（关闭时填）。

怎么"领走"一条需求

在待认领分段点一条需求 → 直接进「新建任务」页：来源自动锁定为「需求池」、关联需求已经选好、任务名和描述用需求内容预填（可改）→ 提交 → 这条需求变成「已领走」，同时生成一条任务。领走是原子动作，两个人同时点也不会被领两次。

"领走"不是一个单独的按钮，它就是"就这条需求建一个任务"这个动作本身 —— 多一层按钮等于同一个意图点两次。

需求自己会流转（生命周期）

需求的四个状态：待认领 → 已领走 → 已完成 / 已关闭。多数变化是自动的，不用手点：

事件结果
新建一条需求待认领
被领走（= 基于它建了任务）已领走
下面的关联任务全部完成自动变成 已完成
任务被删光（没人在办了）退回 待认领（让下一个人接）
决定不做了，手动关闭（填原因）已关闭
已关闭的需求手动重新打开回到 待认领
「已关闭」不会被自动改动 —— 一个"我决定不做了"的结论，不该被隔壁任务的状态变化悄悄推翻。想再做就点「重新打开」。

谁能建 / 改 / 关

  • 所有人（含管理者）都能把想法记进需求池（新建需求）。
  • 提出人、领走人、管理员能改需求内容、能关闭 / 重开。
  • 管理者（只读角色）能看需求池、能建需求、能改能关自己提的那条 —— 但他领不走（领走 = 建任务，他被拦在门外）。
  • 别人提的需求，你领不走也改不了、关不掉，只能看着它或被你领。
顺带一提：任务「来源」里的 「业务部门提报」已改名为「需求池」，历史任务的来源会一并更新显示。

三个框，至少填一个

  • 进展描述 —— 做了什么、现在什么结果。想用语音就长按输入法的麦克风说话，不用装插件。

AI 精简：把口语整理成规范的进展（重点功能）

★ 强烈建议用起来。上报进展时，无论你是长按说话转成文字，还是手打，内容往往夹着口语、口头禅和错别字。点一下「AI 精简」，它会结合当前任务的名称与目标，把这段内容：理顺语句、改正错别字、压到 50 字左右，并自动把里面的「卡壳 / 需要支持」分离到对应框里。原文没提到的东西它绝不会瞎编。

这一下能省掉大量"回头整理纪要"的功夫 —— 提交上去的就是一段干净、规范、可直接给领导看的进展。使用要点：

  • 必须先在上面输入框写好内容（语音或手打都行），空内容时点不动。
  • 精简结果写回输入框，不满意可以接着改、或重新写 —— AI 只是帮你起草，最终你说了算。
  • 刚精简完按钮变「已精简」并置灰；你再改一次内容，它又变回可点。
  • AI 出问题或没启用时不会挡住你：会提示原因并保留原文，照常提交（精简是锦上添花，不是必经步骤）。
没输入内容时 —— 点不动AI 精简

刚精简完 —— 变「已精简」并置灰，再改一次内容才重新可点已精简
「AI 精简」由后台的 DeepSeek 模型驱动，需要在云函数 callAI 上开启（管理员配好开关与密钥后即自动可用）。启用后所有人在上报进展时都能点；没启用时该按钮点了会提示"AI 精简未启用"，不影响正常提交。

提交

提交失败直接重试即可，不会产生重复记录 —— 系统按提交令牌去重，网络抖动时反复点也安全。

⑥建 / 改任务

新建任务

报任务页最下方「新建任务」入口。表单要填：任务名称、任务详情 / 目标描述、分类、来源，人员（普通同事主办人固定是本人，管理员可以选别人；协办人可多选），以及计划开始 / 截止时间。

「任务性质」里选计划性 / 周期性 / 临时性时，只是给这条任务加个标注；另外还能填一个可选的「周期频率」，记下它重复的规律。

建周期计划（定期自动生成任务）

要让系统按期自动生成任务（例如「每月写报告」），先把表单里的「任务性质」改成周期性 —— 表单会切换成创建一份计划（模板），按钮也变成「创建计划」。

计划 ≠ 任务

建计划时不会立刻产生任务。计划只是一张模板，躺在那里等着按期开工。

到了每期开始日，系统自动生成当期任务，任务名 = 计划名前面加上期间（例：2026年10月 写报告）。

排期怎么填

先选「多久一次」（每月 / 每季 / 每年），再填期内偏移：

每月 → 第几号开始、第几号截止；
每季 → 第几个月 + 几号；
每年 → 几月 + 几号。

生成出来的任务，报进展、改状态与普通任务完全一样。

计划的归属规则与新建任务一致：谁建的谁管，管理员管全部。改设置或删除只影响以后，已经生成的历史任务一律不动。本期已经过完的时间段不会补生成。

改任务

改任务页点卡片 → 编辑：任务名、详情、分类、来源、进度、时间、协办人；最底部是删除该任务（只有主办人和管理员看得到，删除后任务与全部进展记录都无法恢复）。主办人不能换人 —— 要换只能重建。

同一个页面底部还有两个入口行：

管理我的计划
周期性计划：看排期、改设置或删除

需求的规矩比任务松一档：谁提的谁做主，别人提的也能领去办，但改不了、关不掉。领走一条需求本身就是建一个任务 —— 所以能建任务的人才能领需求。

⑨常见问题

报任务页顶上出现「10 天以上没有新进展」，是什么？

你主办或协办的任务里，超过 10 天没人报过进展的会被拎到最上面 —— 位置本身就是提醒，免得它们沉在几十条里。超过 5 条会折起来，点「展开其余 N 项」看全。点任意一行直接进上报页。报了进展它自己就消失了。

「自动生成 N 项待跟进」又是什么？

周期计划到点自动生成的任务，落到你头上还没人碰过（没进展、进度 0、还是未开始）。看到了就说明该动了。你一旦上报过进展，它就从这里消失，正常混在「我主办的任务」里。

为什么我改不了进度和状态？

因为你是这条任务的协办人。进度、状态、阶段只有主办人能改 —— 协办的界面上这几个框根本不显示。你可以提交进展描述、卡壳和需要支持。

任务不见了？

先看是不是落到了「已完成」分组（默认收起，点标题展开）。再看是不是在任务看板的别的分段里。都没有的话，可能是被主办人或管理员删除了。

同事在人员看板里点不进去？

他还没认领姓名。让他自己打开一次小程序完成认领，之后管理员在人员看板点「把历史任务关联到已认领的同事」，历史任务的主办 / 协办归属就会补齐。

我的名字打错了 / 我想改显示的名字？

小程序里改不了，请联系管理员在后台名单里改。
